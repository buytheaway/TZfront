# AKA landing page

Static HTML/CSS/JS implementation of the supplied Figma export. Open `index.html` in a browser, or serve this directory with any static server.

`design-assets/Landing.png` is a visual reference only and is not loaded by the interface. The page consists of semantic HTML sections, text, links, buttons and forms.

Open `showcase.html` to navigate all reconstructed mockups.

- `index.html` — AKA / `Landing.png`
- `qaztech.html` — Qaztech / `Главная.png`
- `lavellea.html` — Lavellea / `Готовый.png`
- `brucke.html` — BRÜCKE / `v1.png`
- `jetbridge.html?layout=v1`, `v2`, `v2-alt`, `v3`, `v3-alt`, `v4`, `v5`, `v6`, `v7`, `v8` — все варианты JetBridge из экспорта.
